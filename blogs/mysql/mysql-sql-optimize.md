# 【mysql】SQL调优
#### 避免使用select *
select * 会查出所有列的数据，有些列是不需要的，这就会浪费数据库内存和CPU、增加网络IO时长。

#### 用union all代替union
union会去重，而union all不会，所以union all性能高。

#### 使用limit限制数据量
假设已经知道某个查询语句的结果数据量，比如数据量为6行。如果不加limit 6，那么在查询到6行数据之后，还是会继续检索表，浪费资源和时间。

#### 使用连接查询代替子查询
子查询会创建临时表，并且在查询完毕后还需要删除这些临时表，这会有性能消耗。

#### 使用EXISTS代替IN
因为EXISTS一旦找到匹配的记录就会停止子查询。
