# 【mysql】雪花算法Snowflake
雪花算法是一种分布式主键ID生成的解决方案。其生成的ID为64bit的长整型数值，而这64bit可以分为四个组成部分：
* 固定值：1 bit，0 表示正，1 表示负，通常都是固定为 0。
* 时间戳：41 bit，存储毫秒级时间戳，可以使用 69 年。
* 机器码：10 bit，最多可以支持部署 1024 个节点。
* 序列号：12 bit，用于表示在同一毫秒内生成的多个ID的序号，同一毫秒内最多支持生成的4096个ID。

以上长度可以根据实际业务场景自行配置。通常在实现雪花算法时，会采用单例模式，用于维护时间戳和序列号，并且会加锁，用于判断是否为同一毫秒。
