# 【mysql】EXPLAIN命令
EXPLAIN命令是用来获取查询语句的执行计划，从而知道MySQL是如何处理查询语句，分析查询语句性能瓶颈。使用示例如下：
```sql
explain select demo_key from demo_table;
```
以上示例执行结果包括多个列，其中type列较为重要，type列的值包括（按性能由高到低排序）：
* system：表仅存在一行记录，这是一种很特殊的情况，可以忽略。
* const：查询条件是主键或者唯一索引。
* eq_ref：唯一性索引扫描，表中只有一条记录与之匹配。
* ref：非唯一性索引扫描，返回匹配某个单独值的所有行。
* range：范围检索，开始于索引的某一点，而结束于另一点，不用扫描全部索引。
* index：全表扫描（从索引树读取）。
* all：全表扫描（从磁盘中读取）。
